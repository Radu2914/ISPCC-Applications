# Notices

This document sets out the terms under which this repository's content may — and may **not** — be used.

---

## 🚫 No AI Training

All content in this repository is **explicitly excluded** from use in AI/ML training, fine-tuning, or dataset collection.

This prohibition covers all human-authored material in this repository, including but not limited to:

- Source code and scripts
- Documentation and comments
- Commit messages and pull request text
- Issue and discussion content
- Any other text or assets

**Prohibited uses include:**

- Training or fine-tuning any large language model (LLM) or other AI/ML system
- Incorporating content into any AI training dataset or corpus
- Using this content to benchmark, evaluate, or prompt AI models at scale
- Any automated process whose purpose or output is to improve an AI system

If you represent an organisation that trains AI models, you do not have permission to use any content from this repository for that purpose.

---

## 🚫 No Automated Crawling or Scraping

Automated access to this repository is **not permitted** except for legitimate uses explicitly listed below.

**Prohibited:**

- Web crawlers and scrapers of any kind
- Automated mirroring or archiving without prior written consent
- Bots harvesting content for resale, aggregation, or redistribution
- Any tool that accesses this repository programmatically at scale

**Permitted legitimate automated access:**

- The GitHub platform's own systems performing normal repository operations
- Security vulnerability scanners operating under a responsible-disclosure policy
- Your own CI/CD pipelines operating on a fork you legitimately control

See [`robots.txt`](./robots.txt) for the machine-readable disallow list.

---

## 🚫 No Automated Translation

The content of this repository **must not** be processed by automated machine-translation services for redistribution or re-publication.

This means:

- Do not feed this repository's content into Google Translate, DeepL, or similar services and republish the output as your own work
- Do not automatically localise documentation or code comments using AI translation without the maintainers' explicit written consent
- Do not redistribute machine-translated versions of this content

Human translators who wish to contribute translations are warmly welcome — please open an issue to discuss.
