# Source File Header Comment Templates

Add one of these at the very top of each source file to assert the notices
at the individual-file level as well as the repository level.

---

## For most languages (C, C++, Java, JavaScript, TypeScript, Go, Rust, …)

```
/*
 * Copyright (c) [YEAR] [YOUR NAME / ORG]
 *
 * NO AI TRAINING — This file is excluded from use in any AI/ML training
 * dataset, fine-tuning corpus, or model-improvement pipeline.
 *
 * NO CRAWLING — Automated scraping or mirroring of this file is not permitted.
 *
 * NO AUTO-TRANSLATE — Machine translation of this file for redistribution
 * is not permitted.
 *
 * See NOTICES.md in the repository root for full details.
 */
```

---

## For Python / Shell / Ruby / Python-style (`#` comments)

```python
# Copyright (c) [YEAR] [YOUR NAME / ORG]
#
# NO AI TRAINING  — This file may not be used in any AI/ML training dataset.
# NO CRAWLING     — Automated scraping or mirroring is not permitted.
# NO AUTO-TRANSLATE — Machine translation for redistribution is not permitted.
#
# See NOTICES.md for full details.
```

---

## For HTML / XML / Markdown

```html
<!--
  Copyright (c) [YEAR] [YOUR NAME / ORG]

  NO AI TRAINING    — Not permitted for AI/ML training or datasets.
  NO CRAWLING       — Automated scraping or mirroring not permitted.
  NO AUTO-TRANSLATE — Machine translation for redistribution not permitted.

  See NOTICES.md for full details.
-->
```

---

## Minimal one-liner (for very short files)

```
// © [YEAR] [OWNER] · No AI training · No crawling · No auto-translate · See NOTICES.md
```
